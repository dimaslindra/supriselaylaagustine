PINK SURPRISE WEBSITE 💗
===========================

Cara pakai:
1. Buka file index.html dengan browser.
2. Edit nama di file script.js:
   partnerName: "Nama Pacar"
   yourName: "Nama Kamu"
   relationshipStart: "2026-01-01"

3. Masukkan media Anda ke folder "assets" dengan nama:
   - foto1.jpg
   - foto2.jpg
   - foto3.jpg
   - cover-video.jpg
   - video1.mp4
   - musik.mp3

4. Jika ingin mengganti tulisan/pesan cinta, edit langsung pada index.html.

5. Website sudah responsive untuk HP dan laptop.

Tips:
- Foto portrait cocok untuk foto1.jpg.
- Foto landscape cocok untuk foto3.jpg.
- Video sebaiknya MP4 H.264 agar mudah diputar browser.
- File musik MP3 bersifat opsional.
